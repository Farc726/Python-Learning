## 实践项目：教务管理系统（v1 → v5 迭代）

同一个系统用不同阶段的知识反复重构，是理解"代码可以越写越好"的最好方式：

| 版本 | 用到的知识 | 文件 |
|---|---|---|
| v1 | 数据容器（列表/字典）实现增删改查 | `第四章 数据存储容器/教务管理系统-v1.py` |
| v2 | 把每个功能封装成函数，主程序只剩菜单循环 | `第五章 函数/教务管理系统-v2（函数）.py` |
| v3 | 文件操作 + json：数据存盘，重启不丢失 | `第七章 文件操作/教务管理系统-v3（文件）.py` |
| v4 | 面向对象重构：把学生和系统抽象成类 | `第十章 面向对象基础/教务系统-v4（类和对象）.py` |
| v5 | 异常处理：输入错误不崩溃，文件异常有兜底 | `第十一章 异常/教务管理系统-v5（添加异常处理）.py` |

另有一个面向对象练习项目：`第十章 面向对象基础/购物车管理系统实例.py`（商品增删改查 + 字典嵌套结构）。

学习的收获与踩坑记录见 `exercises/教务系统总结.txt`。

## 学习方法

1. **一个知识点一个文件**：不把旧代码注释着堆在同一个文件里（旧版本交给 git 保存）
2. **先自己写，再看教程对照**：例如 `第五章 函数/09-1 案例-2(自己写).py` 和 `09-2 案例-2（看教程后）.py`
3. **每天提交**：提交信息写清当天学了什么，形成学习日志
4. **自己 debug 找错**：遇到报错先读报错信息、自己定位，再把易错点记进注释和总结

## 运行方法

环境：Python 3.13 + 虚拟环境（`.venv`）

1. 激活虚拟环境

       .venv\Scripts\activate

2. 运行任意练习文件（大部分是控制台程序，直接运行即可）

       python "exercises/第五章 函数/01 定义.py"
